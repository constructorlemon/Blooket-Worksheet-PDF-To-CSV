Simple web tool created using OpenCode (vibe coding) to make it easy to convert Blooket quizzes into a CSV file. Blooket doesn't let you do this, but they do let you export a worksheet. Here's how to use the tool:
1. Export an answer key version of your Blooket quiz on Blooket
2. Put the pdf into the tool
3. Get CSV!

Here's the link to the website: https://constructorlemon.github.io/Blooket-Worksheet-PDF-To-CSV/ 

I built this in 2 prompts and in about an hour since I wanted to convert my Blooket into a Gimkit for my students but couldn't find an online solution. I don't support the way AI companies are run, but I think vibe coding is a pretty neat technology for small use cases like this. 

Here's the 2 prompts I used:

Prompt 1: Here's my problem: I need to download my Blooket Quiz into a CSV file so I can convert it into a Kahoot/Gimkit. I've attached the pdf file and a sample csv file below. Write a script and run it using the pdf to give me a csv file with all 100 of the questions.

Prompt 2: Hmm, I think this would be a cool thing to put online. Make an html/js/css version with minimal UI which allows you to upload a pdf and download the resulting csv file. Include warnings about how multiple correct answers will only keep the first and a output report that lists all the questions with multiple correct answers.
